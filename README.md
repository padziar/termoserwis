# TermoSerwis: system obsługi zgłoszeń i dostępności pracowników

> **Uwaga:** TermoSerwis sp. z o.o. to firma **całkowicie fikcyjna**, a wszystkie dane w aplikacji są wygenerowane. Projekt powstał w celach edukacyjnych i do portfolio.

**Status:** w budowie. Aplikacja jeszcze nie działa.

## 1. Czym jest ta aplikacja i dla kogo

TermoSerwis montuje i serwisuje pompy ciepła oraz klimatyzację. Aplikacja ma pomagać w codziennej pracy firmy:

- **klienci** zgłaszają awarie i sprawdzają status naprawy,
- **konsultanci** przyjmują zgłoszenia i ustalają priorytety,
- **kierownicy** zatwierdzają, który technik pojedzie do klienta,
- **technicy** widzą swoje zadania,
- **HR** zarządza urlopami pracowników.
