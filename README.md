# TermoSerwis: service request and staff availability system

> **Note:** TermoSerwis sp. z o.o. is a **completely fictional** company, and all data in the application is generated. This project was created for learning and as a portfolio piece.

**Status:** under construction. The application does not run yet.

## 1. What this application is and who it is for

TermoSerwis installs and services heat pumps and air conditioning. The application is meant to help with the company's daily work:

- **customers** report failures and check the repair status,
- **consultants** receive requests and set priorities,
- **managers** approve which technician visits the customer,
- **technicians** see their own tasks,
- **HR** manages employee leave.
